5. FORMS & DATA COLLECTION
--------------------------------------------------
Method: Web3Forms (https://api.web3forms.com/submit)
Forms:
  - heroForm (name, city, email) -> Web3Forms
  - waitlistForm (name, city, email) -> Web3Forms
Fields (hidden): access_key, subject, redirect (https://www.proximi.in/thanks), botcheck (honeypot)
Submission: fetch() POST, inline success message, no page redirect
Entries: Web3Forms dashboard + email, CSV export
Access key: embedded in index.html (replace if rotated)
